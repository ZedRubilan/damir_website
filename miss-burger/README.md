# Miss Burger — сайт

Одностраничный сайт ресторана в одном файле `index.html` (HTML + CSS + JS, без сборки).
Внешние зависимости — только three.js 0.180.0 и Lenis (через import map с jsDelivr) и шрифты Google Fonts.

## Страница меню — `menu.html` (на русском)

Наверху — компактный 3D-логотип, статус «Открыто/Закрыто» и номер столика. Сразу под ним —
закреплённая строка категорий и кнопка «Вызвать официанта», дальше «бумажное» меню с рисунком
у каждого блюда, внизу — контакты. Фон — спокойный анимированный градиент.

Фон — на выбор, кнопкой с палитрой в углу (выбор запоминается): «Градиент», «Узор» (линейные
бургеры, фри, шейки), «Бегущая строка», «Дайнер» (клетчатый пол и закат за логотипом), «Огни».
По умолчанию — `SITE.background`; ссылка `menu.html?bg=diner` открывает сразу нужный фон;
`SITE.backgroundSwitch: false` прячет кнопку от гостей.

- Блюда, цены, состав, вес, метки «Хит»/«Острое» — в константе `MENU` в начале скрипта.
- Контакты, адреса, часы работы, число столиков — в `SITE` там же.
- Фото блюда: положите файл в `assets/menu/` под именем, указанным у блюда в `MENU`
  (последнее поле, например `01-classic.webp`) — фото встанет вместо рисунка. Лучше квадратные, от 400×400.

### Столики и «Вызвать официанта»

На каждый стол — свой QR-код со ссылкой `…/menu.html?table=5` (5 — номер столика).
Гость видит «Столик №5»; без номера в ссылке он может выбрать столик сам.
Кнопка предлагает: позвать официанта, попросить счёт, приборы и салфетки. После вызова кнопка
становится зелёной с таймером (повторно — через `SITE.waiter.cooldown` секунд).

Чтобы вызов доходил до официантов, заполните `SITE.waiter` (пока пусто — демо-режим, и панель
пишет об этом):

- `telegram: { botToken, chatId }` — быстрый вариант: создайте бота у @BotFather, добавьте его в чат
  официантов, впишите токен и id чата. Сообщение придёт как «🔔 Столик №5: Позвать официанта».
  Минус: токен бота виден в коде страницы — кто угодно сможет слать сообщения от его имени.
- `endpoint: "https://…"` — надёжный вариант: свой сервер (или Google Apps Script), получает
  POST с JSON `{table, request, text, at}` и пересылает куда нужно; токен остаётся на сервере.

## Что заменить на реальные данные

Все данные о ресторане лежат в одной константе `SITE` в начале `<script type="module">`
в `index.html`. Значения в «ёлочках» — заглушки, их нужно заменить:

- адреса трёх точек (`locations`), часы работы (`hours`);
- e-mail, телефон, домен (печатается под штрихкодом на чеке);
- ссылки Instagram / Telegram;
- названия и цены четырёх позиций меню (`menu`) и напитка в карточке на первом экране (`drink`).

Цены в «бумажном меню» за кнопкой VIEW FULL MENU прописаны прямо в HTML (блок `menu-receipt`).

## Фотографии (необязательно)

Пока файла нет, вместо него показывается нарисованная иллюстрация. Положите вырезанные
на прозрачном фоне фото (webp) в эти пути:

| файл | размер |
|---|---|
| `assets/menu/01-classic.webp` | 1216×1293 |
| `assets/menu/02-double.webp` | 1024×1536 |
| `assets/menu/03-shake.webp` | 1024×1536 |
| `assets/menu/04-fries.webp` | 1536×1024 |
| `assets/locations/shake.webp` | 1024×1536 |
| `assets/order/bg-table.webp` | 1440×800 (обычное фото, не вырезка) |

Логотип: `assets/shared/logo-mask.webp` (маска, встроена в `index.html` как `--logo-mask`)
и `assets/shared/logo-color.webp` (фавиконка).
