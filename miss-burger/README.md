# Miss Burger — сайт

Одностраничный сайт ресторана в одном файле `index.html` (HTML + CSS + JS, без сборки).
Внешние зависимости — только three.js 0.180.0 и Lenis (через import map с jsDelivr) и шрифты Google Fonts.

## Страница меню — `menu.html` (на русском)

Меню — первое, что видит посетитель: шапка с кнопкой «Заказать по телефону» и закреплённая
строка категорий (Бургеры, Курица, Закуски, Соусы, Напитки). Под ней «бумажное» меню
с рисунком у каждого блюда. Внизу — 3D-логотип, который «кусает» котлету, и контакты.
Фон: анимированный градиент и летающий кунжут.

- Блюда, цены, состав, вес, метки «Хит»/«Острое» — в константе `MENU` в начале скрипта.
- Контакты, адреса, часы работы (по ним же горит «Открыто/Закрыто») — в `SITE` там же.
- Фото блюда: положите файл в `assets/menu/` под именем, указанным у блюда в `MENU`
  (последнее поле, например `01-classic.webp`) — фото встанет в карточку вместо рисунка.
  Лучше квадратные фото от 400×400.

## Что заменить на реальные данные

Все данные о ресторане лежат в одной константе `SITE` в начале `<script type="module">`
в `index.html`. Значения в «ёлочках» — заглушки, их нужно заменить:

- адреса трёх точек (`locations`), часы работы (`hours`);
- e-mail, телефон, домен (печатается под штрихкодом на чеке);
- ссылки Instagram / Telegram;
- названия и цены четырёх позиций меню (`menu`) и напитка в карточке на первом экране (`drink`).

Цены в «бумажном меню» за кнопкой VIEW FULL MENU прописаны прямо в HTML (блок `menu-receipt`).

## Фотографии (необязательно)

Пока файла нет, вместо него показывается нарисованная иллюстрация. Положите вырезанные
на прозрачном фоне фото (webp) в эти пути:

| файл | размер |
|---|---|
| `assets/menu/01-classic.webp` | 1216×1293 |
| `assets/menu/02-double.webp` | 1024×1536 |
| `assets/menu/03-shake.webp` | 1024×1536 |
| `assets/menu/04-fries.webp` | 1536×1024 |
| `assets/locations/shake.webp` | 1024×1536 |
| `assets/order/bg-table.webp` | 1440×800 (обычное фото, не вырезка) |

Логотип: `assets/shared/logo-mask.webp` (маска, встроена в `index.html` как `--logo-mask`)
и `assets/shared/logo-color.webp` (фавиконка).
